# Sistema de Gestión de Clientes - "Justicia para Todos"

Este proyecto es una aplicación web full-stack desarrollada para la firma de abogados "Justicia para Todos", que permite gestionar de manera eficiente la información de sus clientes y los casos legales asociados.

### Características 

* **Gestión Integral de Clientes:** Permite registrar, modificar y eliminar la información completa de los clientes y sus casos legales asociados.
* **Formulario de Casos Detallado:** Un formulario completo para administrar los datos del cliente y los detalles del caso, incluyendo número, descripción, estado (activo, en proceso, cerrado) y fechas clave.
* **Visualización en Tiempo Real:** Muestra un listado siempre actualizado de todos los clientes registrados, permitiendo un seguimiento claro del estado de cada caso.
* **Operaciones CRUD Completas:** Implementa la creación, lectura, **modificación** y eliminación de registros, garantizando una gestión completa del ciclo de vida de los datos del cliente.
* **Backend Integrado:** Toda la lógica del servidor y la conexión a la base de datos se manejan de forma eficiente a través de las rutas de servidor nativas del framework.

---

### Tecnologías

* **Framework:** NuxtJs.
* **ORM:** Prisma para una gestión de la base de datos moderna y segura.
* **Base de Datos:** **MySQL**, como se requiere en la tarea, para asegurar una solución robusta y escalable.
* **Estilos:** CSS plano integrado directamente en el componente de Vue para un diseño limpio y funcional.
